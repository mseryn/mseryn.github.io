comp125

COMP 125 - Visual Information Processing

Loyola University Chicago — Spring 2026

This course has concluded. Materials are kept here for reference.

Note on dates: Many of the slide decks below have “Spring 2025” printed on their title slides. That date is incorrect — this course ran in Spring 2026. The files are otherwise unmodified.

An introduction to programming for non-majors, using JavaScript and the p5.js visualization library. No prior programming experience required.
