Mantis is an open-source Python toolkit that streamlines performance
monitoring and profiling in high-performance computing (HPC) environments.
It unifies a set of diverse monitoring tools to deliver consistent output,
letting researchers and developers collect and analyze application
performance across different systems without code modifications or root
access.

See also [mantis-dash](/projects/mantis_dash/), the visualization
component of the same suite.
